Every window here is a Svelte app.

gpuix-svelte is a Svelte custom renderer for GPUI, the UI framework behind the Zed editor. There's no DOM and no webview.

$npm create gpuix-svelte@latest my-app

Node.js 24+ or Bun 1.4+, on macOS (Apple Silicon), Windows (x64) or Linux (x64).

Examples

Each one is in the repository's examples/ folder. Clone the repository, run bun install, then the command on the card.

  • Tutorial

    npm run tutorial

    A 12-step interactive guide to the renderer, itself a gpuix-svelte app. From step 3 on, each step runs a component below its code.

  • Control center

    npm run demo:glass

    A translucent panel over macOS vibrancy. demo:glass-ffi puts it on real Liquid Glass via FFI, on macOS 26+.

  • Styling playground

    npm run demo:styling

    Which CSS reaches GPUI and which is dropped, side by side.

  • Hacker News

    npm run demo:hn

    Live network data in a scrolling list: the top stories on 2026-10-15.

  • Tic-tac-toe

    npm run demo:tictactoe

    It keeps score across rounds. This one went to X.

  • Counter

    npm run demo:counter

    The counter after three clicks on +, with a keyed list beside it. It hot-reloads on save.

  • Desktop APIs

    npm run demo:desktop

    Window controls, file picker and drops, live image pixels, selection, focus, accessibility.

  • GPUIX Web

    Tic-tac-toe on the web

    npm run demo:web

    The same component in Chrome, drawn on a WebGPU canvas by GPUI compiled to WebAssembly. Bun builds it.

Apart from demo:web, which always runs on Bun, each command has a Bun twin, such as npm run bun:demo:counter.

Different

  • Elements are GPUI's: div, text, img, svg, input, textarea, code, markdown, virtual-list and a few more. Any other tag renders as a div, with a warning.
  • Mouse events don't bubble. They go to the element under the pointer, and hitbox="self" lets clicks on a button's decoration reach it. Styling
  • CSS is a subset: flexbox in logical pixels, lengths in px or rem, and % or auto only on sizes. Values GPUI can't use are dropped with a warning. Styling [gpuix-svelte] dropped unsupported style value `borderRadius: 50%`
  • There's no bind:. Inputs report through events, with the value in the payload, and {@attach} hands you the element. Guide
  • Theming is var(--token) in your styles plus one set_css_vars({ token: '#fff' }) call. Styling
  • Shortcuts go through on_window_key('keydown', handler), which hears every key, whatever has focus. Guide

In the package

  • Scroller

    A scroll column with a drawn scrollbar. With virtual, GPUI lays out only the rows near the viewport.

  • Portal

    Paints modals, menus and toasts on top, from anywhere in the tree.

  • Tooltip

    A hover tip beside its trigger, on GPUI's native <anchored>.

  • Popover

    A controlled panel beside its trigger, or at the pointer as a context menu.

  • Window helpers

    Title, minimize, zoom, fullscreen, the file picker, file drops, images from raw pixels and focus order.

  • gpuix-svelte/test

    Headless tests that click through GPUI's real hit testing, without opening a window.

  • gpuix-svelte/automation

    Drives a running app's window from another process. It took the screenshots on this page, apart from the control center and the web build.

  • Standalone builds

    The starter's npm run build compiles the app into one executable with Bun inside: about 90 MB on macOS (Apple Silicon).

Quick start

$npm create gpuix-svelte@latest my-app
Created my-app. Next:

  cd my-app
  npm install
  npm start      # opens the window; edit App.svelte to hot-reload
  npm test       # headless test (macOS and Windows)
  npm run build  # standalone executable in dist/ (requires Bun)

A counter opens in its own window. Edit App.svelte, save, and the window hot-reloads.

On Bun, run bun create gpuix-svelte my-app, then cd my-app, bun install and bun run start. To add it to an existing project, run npm install gpuix-svelte, then start your entry with npx gpuix-svelte app.ts.

Status and requirements

Status
Experimental: expect breaking changes between minor versions. Svelte's custom renderer API lives on an open pull request, sveltejs/svelte#18511. Each release bundles the exact Svelte build it was tested against, so gpuix-svelte is the only runtime dependency you add.
Runtime
Node.js 24 or later, or Bun 1.4 or later.
Platforms
macOS (Apple Silicon, Metal), Windows (x64, DirectX) and Linux (x64, Vulkan). The GPUI binary comes prebuilt from npm, so npm install is the whole setup.
Headless tests
macOS and Windows. The Linux prebuild has no test renderer.
Builds
Standalone executables and the web build need Bun, whichever runtime you develop on. A binary is built on the OS it targets.
Release
0.2.0, released 2026-10-13, under the MIT license. Changelog
