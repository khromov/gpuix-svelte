Ten marks for gpuix-svelte

Each one is a single SVG, drawn so it survives a 16 px favicon, a 512 px app icon and a monochrome print. Neutral parts use the surrounding text colour, so the same file works on black and on white; the accent is Svelte’s orange, #ff3e00. Pick one and the rest get deleted.

At a glance
  • 32 / 16 px

    01Window

    A native window, filled with Svelte orange. The title bar and three dots are the one shape every desktop user reads as “an app window”, and the orange body says what is inside it.

    It is literal, which is its strength: the project’s whole pitch is that Svelte ends up in a real window. The dots still read at 16 px. The risk is looking like a generic “desktop app” icon rather than a brand.

  • 32 / 16 px

    02Triangle

    The GPU’s one primitive. Everything GPUI paints is triangles, and a single orange triangle is the most honest way to say “drawn on the GPU”. It is also a delta, the symbol for change, which is what a reactive framework ships every frame.

    Scales to any size and stays one colour. It is also the most anonymous of the ten: many graphics projects use a triangle, so it needs the wordmark next to it to be recognisable.

  • 32 / 16 px

    03Panes

    Three layers, the front one solid. Component, shadow tree, native window: the mark draws the pipeline as depth, with the two outlines fading back and the orange pane in front being the one you can touch.

    Reads as stacked windows too, which fits a desktop toolkit. It has the most parts, and at 16 px the back outlines blur into a halo, so the favicon would be the front square alone.

  • 32 / 16 px

    04Monogram g

    A geometric lowercase g. Ring plus hook, two strokes of equal weight, in the spirit of Geist, the typeface the site is set in. The first letter of gpuix and nothing else.

    Ownable and quiet; a letter mark is the usual choice for a library. It says nothing about windows or GPUs, so it leans on the name for meaning, and the hook thins out at 16 px.

  • 32 / 16 px

    05Wordmark tile

    The name on a black square. This is what the site already uses for the favicon and for the app icons in the Shipping section, so choosing it changes nothing and keeps the mark and the name identical.

    Unambiguous at 48 px and above, where the text is legible; below that it becomes a black square with a grey smudge. No colour, which is either restraint or a missed chance, depending on taste.

  • 32 / 16 px

    06Brackets

    Markup, with a window where the tag name goes. The angle brackets are the Svelte side (you write components), the orange block between them is the native side (you get a window). Read left to right it is the whole renderer in one glyph.

    Developers decode brackets instantly, and it is the only candidate that shows both halves of the project. At 16 px the brackets thin to hairlines, so the favicon needs a heavier cut.

  • 32 / 16 px

    07Tiles

    Four panes, one lit. A window grid, a flexbox layout, GPU tiles: the two-by-two reads as all of them, and the single orange tile marks the one thing that is different, your Svelte component.

    The most robust of the ten at small sizes, since it is four blobs. It sits close to the Windows logo and to a dozen dashboard products, which is the reason to be careful with it.

  • 32 / 16 px

    08Split square

    One square, two halves. JavaScript and the GPU share one process, and the diagonal is the batch boundary between them: the neutral half is yours, the orange half is drawn. It is an app icon shape by construction.

    Bold, flat and impossible to misrender at any size. It is also the most abstract, so it carries no hint of windows or Svelte beyond the colour.

  • 32 / 16 px

    09Reload

    Save, and the window comes back. An orange arc around a small window: hot reload, the first thing the starter shows you, and the frame loop that redraws every tick.

    Friendly and dynamic, and the arrow survives 16 px better than expected. The shape is shared with every “refresh” button on earth, so on its own it reads as an action, not a product.

  • 32 / 16 px

    10Pointer

    The desktop’s own cursor, in orange. Nothing says “not a web page” like the arrow that lives outside the browser. It points at the one fact the headline makes: these are desktop apps.

    Instantly recognisable and strong at every size. Its weakness is that it is borrowed: the arrow belongs to the operating system, so it looks like a tool for automation or remote control as readily as a UI framework.
