Build native desktop apps with Svelte

gpuix-svelte renders your Svelte components into a native, gpu-accelerated application on macOS, Windows and Linux, with no browser. You can access anything on the user's computer using Node or Bun APIs.

$npm create gpuix-svelte@latest my-app
Read the docsView on GitHub

Quick start

Scaffolding a gpuix-svelte application is easy, you'll need Node.js 24 or later, or Bun 1.4 or later.

On Bun, run bun create gpuix-svelte my-app, then cd my-app, bun install and bun run start.

$ npm create gpuix-svelte@latest my-app
Created my-app. Next:

  cd my-app
  npm install
  npm start      # opens the window; edit App.svelte to hot-reload
  npm test       # headless test (macOS and Windows)
  npm run build  # standalone executable in dist/ (requires Bun)

How it works

gpuix-svelte uses the experimental Svelte custom renderers feature, which lets the compiler emit calls to a renderer of your choice.

gpuix-svelte maps ordinary Svelte components onto GPUI, the GPU-accelerated UI framework behind the Zed editor, through Svelte’s unreleased custom renderer API. Your markup, runes and <style> class rules compile as usual, and every element becomes a GPUI node. Hot reload

gpuix-svelte has built-in hot reloading, just like you’re used to. Save a file and the open window updates in place.

starter/App.svelte

	.primary {
		background-color: #a6e3a1;
		color: #1e1e2e;
		background-color: #ff3e00;
		color: #ffffff;
	}

[gpuix-svelte] remount complete

Shipping

You can easily ship self-contained, signed executables on Windows, Mac and Linux. npm run build bundles your app, the runtime and GPUI into a single file. The shipping docs cover the macOS .app, signing and notarization, and the same app can also run in a browser on GPUI’s WebAssembly build.

Coming from Svelte on the web

Most of the things you know and love from Svelte work out of the box, but some things are different in the native gpuix environment.

Works as usual

  • $state
  • $derived
  • $effect
  • $props
  • {#snippet}
  • {#each}
  • {#if}
  • {#await}
  • <svelte:boundary>
  • .svelte.ts
  • <style>
  • class:
  • style:
  • {@attach}

Different

HTML elements map to native equivalents
A fixed set of tags: div, text, img, input, textarea, markdown, virtual-list and a few more. Anything else renders as a div, with a warning.
Mouse events don’t bubble
They go to the element under the pointer. hitbox="self" on a clickable element lets clicks on its icons and badges reach it. More in the styling docs.
No bind:
Inputs report through events with the value in the payload, and {@attach} hands you the element. More in the guide.
Keyboard shortcuts
on_window_key('keydown', handler) hears every key, whatever has focus. More in the guide.
Theming
var(--token) in your styles and one set_css_vars() call. A theme switch restyles in one batch. More in the styling docs.
Included utilities
Scroller, Portal, Tooltip and Popover, plus helpers for the window, the file picker, file drops and focus. More in the components docs.
